# 319枚・k=100・19候補の所見対応再確認

2026-09-25。元データはoutputs/0003_20260912_control_absent_cluster_mining/cluster_mining_ccl4。
cluster_assignments.parquetから各slideのクラスタ占有率を再構成。
保有の定義は占有率>0.001。元の19候補を固定し、候補選びはやり直していない。

historical_319_associations.csvは保存済みk=100の15所見との対応表に保有内率・recallを追加。
known_labels_299_associations.csvはdose_level不明20枚を除き、同じ19候補に対し
lib.cluster_analysis.finding_associationsで再検定したもの。
cluster_summary.csvはq<0.05の所見のうち保有内率最大（同率はqが小さい方）を代表にし、
他の有意な所見・化合物集中度も記録する。複数所見から最大を取るため探索的な要約であり、
独立検証された正解率ではない。

| 指標 | 当時319枚 | 不明を除外した299枚 |
|---|---:|---:|
| 何らかの所見と有意な候補 | 19/19 | 19/19 |

保有内率はP(スライドに所見の記録あり | クラスタを保有)。パッチ内に所見が写る確率ではない。
所見別recallも保存しており、高い保有内率だけで全所見を広く拾えたとは判断しない。

当時の例:
- cluster0/55/77: 顆粒状好酸性変性15/15、肥大13/15、全保有slideがWY-14643。
- cluster21: 顆粒状好酸性変性10/10、肥大9/10、全保有slideがWY-14643。
- cluster42/53: 脂肪変性9/10、10/11。主にcholesterol。
- cluster5: 脂肪変性55/59、細胞浸潤52/59。全保有slideがCCl4。
- cluster81: 好酸性変化・出血・線維化・細胞浸潤が各8/9。主にmonocrotaline。
- Necrosisの有意対応はcluster42=3/10、53=4/11、81=6/9。
  Single cell necrosisはcluster29=5/9。これらの壊死ラベルについて当時80%以上の対応はない。

結論: 当時の所見とのslide単位の関連は強かったが、化合物・複合表現型との関連も強い。
不明20枚の除外でこの関連が消えるわけではなく、CCl4由来候補の保有内率はむしろ上がる。
大規模化による変化を調べる際は、これらの画像・座標を固定してクラスタ帰属の移動を追う。
