# 規模を上げる前後のクラスタリング比較

比較対象は0003の `cluster_mining_ccl4`（319枚、9化合物、k=100）と、0009の
`kmeans_k_sweep_part0` / `part3`（3,441枚、44化合物、k=100 / 2,000）。
保存済みクラスタ割当を描画し、クラスタリングの再学習はしていない。

## この図から説明できること

大規模版では旧クラスタが細分化し、多くの旧候補パッチは候補群に残る。
一方、cholesterol脂肪変性に関連する旧42/53のように、主要なパッチ群が
クラスタとして残っていても、全体を比較対象とする候補選定では落ちる例がある。
「規模拡大によってすべてのクラスタが崩れた」という説明にはしない。

ディスカッションでは、例えば次のように説明できる。

> 小規模では所見に関連するパッチ群を拾えたため、対象を319枚から3,441枚に広げた。
> 旧クラスタの多くは大規模版でも残るが細分化し、まとまりが保たれていても
> 候補選定から外れる例があった。候補選定やクラスタリング条件を変える試行も行ったが、
> 所見との対応や再現性に課題が残っているため、次は試験単位で実験する。

試行錯誤の結果については、この図だけでなく
[0011](../../0011_20260925_stratified_candidate_selection/README.md)・
[0012](../../0012_20260928_compare_clustering_methods_at_scale/README.md)・
[0013](../../0013_20260929_stable_candidate_layer_review/README.md)を根拠とする。
試験単位の実験は0014の設定に合わせ、「化合物×時点」とする。
この可視化では0014の結果を評価していない。

## 比較の条件・限界

- 2D配置は大規模版のキャッシュ済みPCA64特徴量から一度だけt-SNEで作成し、
  全図で共通の座標を用いる。元のUNI2-h特徴量はL2正規化済み。
  図を作るために小規模版のPCAやクラスタ割当を変更してはいない。
- 散布図は標本による説明用。2Dでの距離・重なりから、病理診断、クラスタの品質、
  元の高次元空間での分離を確定しない。
- 小規模版と大規模版でk、PCAの学習対象、クラスタ学習サンプル数
  （50万 vs 20万）、全パッチの割当方法（重心への直接割当 vs 近傍多数決）が異なる。
  大規模k=100との比較はkを揃えるが、規模だけを変えた因果実験ではない。
- 図の候補数は旧19、大規模k=100で6、k=2,000で330。
  組織割合フィルタを適用する前の統計候補。
  条件は占有率>0.001、Control占有率95%点<0.001、片側U検定のBH q<0.05、
  min_compounds=1、min_treated_presence=0。検定はスライド単位。
- パッチの追跡は元319枚全体を使用。
  大規模版の候補評価はunknownと重複個体を除いた3,357枚。
  脂肪変性の候補選定比較では元コーパスも監査後の299枚を使用する。
  旧19候補は当時の319枚による選定を保持している。

## 再現

```bash
OMP_NUM_THREADS=8 OPENBLAS_NUM_THREADS=8 MKL_NUM_THREADS=8 \
  .venv/bin/python scripts/visualize_clustering_scale.py
```

既存のt-SNE配置を使用して図だけ再生成する場合は `--reuse-layout` を付ける。
新規配置を別フォルダーに生成する場合は `--out-dir` を指定する。

- `sample_layout.parquet`: 抽出パッチ、元座標、キャッシュ索引、クラスタID、共通t-SNE座標。
- `original_cluster_splitting.csv`: 全パッチに基づく分割と候補保持の集計。
- `fatty_candidate_loss.csv`: 旧42/53の主要移動先と比較対象別q値。
- `full_patch_agreement.csv`: 全照合パッチでのARI/NMI。粒度の違いに影響されるため、
  病理的な品質の評価値として使用しない。
- `provenance.json`: 入力ファイル、乱数seed、条件、入力のSHA256。

既存の全パッチ照合・集計の詳細は [scale_trace](../scale_trace/README.md) を参照。
