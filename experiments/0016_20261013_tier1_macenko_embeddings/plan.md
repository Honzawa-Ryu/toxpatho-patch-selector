# 0016 tier1コーパス全体のMacenko正規化埋め込み

染色正規化は基本必須（2026-10-13ユーザー方針）。tier1コーパス3,441枚の既存特徴量（0001/0007/0008のTRIDENT出力）は
正規化されていないため、0005の手順を全体に広げて埋め込み直す。**準備のみ。投入時期はユーザーが決める。**

## 手順

- 座標は既存のTRIDENT出力（`0009/features_tier1_corpus`のsymlink先）を再利用。セグメンテーションとタイル分割はやり直さない。
- 参照染色はコーパス全体の平均的な色味とする（2026-10-13ユーザー方針）。44実験それぞれのControlから2枚ずつ（計88枚）、各20 patchを無作為に取り、Macenkoで推定する。seed固定で全chunk共通、`reference.json`に保存。
- 参照が0005（8実験のControl 16枚）と異なるため、0005の219枚も含めて全3,441枚を作り直す。
- 各slideの染色推定はslide内40 patch、乱数はslide IDから決める（chunk分割に依存しない）。0005は通しの乱数だったため、同じslideでも推定patchは0005と一致しない。
- エンコーダ・推論経路は0005と同一（UNI2-h、TRIDENTと同じautocast）。抽出部品は0005の`experiment.py`から読み込む。
- 染色推定に失敗したslideは正規化なしで混ぜず、スキップして`results.json`に記録する。
- 出力: `outputs/0016_20261013_tier1_macenko_embeddings/20x_256px_0px_overlap/features_uni_v2_macenko/<slide_id>.h5`（0001と同じレイアウト）。

## 実行

- array 4本（`--chunk 0..3`、slide ID順に4分割）、各GPU 1枚・8 CPU・55GB・上限36時間（0008と同程度）。
- 見込み: 3,441枚。0005の実績（約1分強/枚）から、1本あたり約860枚で16〜21時間。
- 途中で止まっても、作成済みの`.h5`は飛ばして再開できる（`.h5.tmp`から原子的に置換）。
