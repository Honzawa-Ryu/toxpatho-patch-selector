# 0005 plan — 染色正規化した埋め込みの再抽出

## 問い

0004で、病変が一切無いcontrolスライド同士が由来する実験で有意に分離することが分かった
（silhouette 0.175, z=31.9）。染色バッチが埋め込みに乗っている。
クラスタ＝視覚トークンがバッチ不変でないなら語彙が染色条件で汚染されているので、
エンコーダに入れる前の画像段階で染色を揃えたら何が変わるかを見る。

## 手順

- Macenko正規化（`lib/stain.py`）。染色ベクトルはスライド単位で1回推定し、
  正規化自体はOD空間の3x3線形写像に畳んで、patchごとのコストを行列積1回にする。
- 座標は0001の計算結果を再利用（画素値を変えてもセグメンテーションとタイル分割は同じ）。
- エンコーダと前処理はTRIDENTのものをそのまま使う。
- 出力は0001と同じレイアウトにして、0003/0004が `features_dir` の差し替えだけで読めるようにする。

## 実装で踏んだ罠

1. **固有ベクトルの符号が不定**。第1軸が平均OD方向と逆を向くと射影角が±πの切れ目を
   またぎ、パーセンタイルが分布の両端ではなく切れ目の両側を拾う。染色ベクトル2本が
   ほぼ平行に潰れ、`max_c` が 9.9 / 29.1 に発散した（正常は1〜2）。
   第1軸を平均OD方向に揃えて解決。cos(H,E)>0.99 で例外を投げる保険も追加。
2. **文献既定の参照濃度がこの切片群より淡い**。`MAXC_REF=[1.97, 1.03]` に対し、
   手元のcontrol 16枚から推定すると [2.56, 1.69]。既定値に合わせると褪色し、
   好酸性の強弱そのものが手がかりである所見（ground glass等）を潰す。
   参照はデータ内のcontrolから推定する方式にした。

## 検証

- **抽出経路が0001と完全一致**: 正規化を切って自前パイプラインで抽出した特徴量と
  0001の特徴量の cos類似度が **1.0000**。「正規化の効果」と「抽出経路の差」が
  混ざっていないことを保証している。変更時は必ず再確認すること。
- 正規化あり/なしの埋め込みの cos は 0.958。効いているが壊してはいない。

## 結果（2026-09-13 / job 10669 / 219枚 4h57m）

正規化前の染色濃度は実験ごとに大きく違う（`stain_fits.parquet`）:

| | max_c_h（ヘマトキシリン） | max_c_e（エオジン） |
|---|---|---|
| 最小 | vitamin A 1.425 | ethambutol 1.208 |
| 最大 | cholesterol 2.775 | thioacetamide 1.828 |

1.5〜1.9倍の開きがある。バッチ差の実体がここに出ている。

### 結論

**染色正規化はバッチ署名をほとんど落とさなかったが、汎化性能は大きく改善した。**

- control同士の実験による分離は 0.175 → 0.153 でしかない（z=31.9 → 31.6）。
  つまり**残っているバッチ署名は色ではない**。切片の厚み・固定条件・スキャナの光学や
  焦点など、色の正規化では触れない要因が効いている。
- それでも LOCO AUROC は 0.635 → 0.741 に上がった。正規化が落とせた部分（色）が、
  化合物をまたぐ転移を最も邪魔していた部分だったということ。
- 処置の信号（0.099 → 0.106）は下がっていないので、正規化が病変の手がかりまで
  消してはいない。事前に決めた2条件のうち、片方（処置の信号の保存）は満たし、
  もう片方（バッチの低減）は満たさなかった。
- **H1は正規化後も棄却されたまま**。同じ `Hypertrophy @ Centrilobular` を持つ
  3化合物の富化クラスタの重なりは、phenobarbital ∩ thioacetamide が cluster 94 を
  1つ共有しただけで、他2ペアは空のまま。
  → **「同じ所見名・同じ部位でも形態は化合物ごとに違う」という0004の結論は、
  染色差では説明できない**。これが今回いちばん確かになったこと。

## 次にやること

- 残るバッチ署名は色ではないので、色の正規化を強めても意味がない。
  決着させるなら**用量反応軸**（同一実験内でControl/Low/Middle/Highを比べる）。
  バッチは用量と直交するので、これは構造的にバッチに汚染されない唯一の検証軸。
  590枚が揃ったので今すぐ使える。
- vitamin A のLOCOが 0.88 → 0.51 に落ちた理由は未確認。Ito細胞の肥大は
  細胞質の色調変化が主体なので、正規化で消えた可能性がある。要確認。
