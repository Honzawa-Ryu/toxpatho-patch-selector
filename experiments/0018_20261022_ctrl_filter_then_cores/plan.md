# 0018 Controlと離れたpatchだけでコアを作る（2段階）

0017 block6_all（cut 0.72の最大の塊、44試験・3,468枚）の結果を受けた次の段（2026-10-22、ユーザー方針）。
0017のt-SNEでは、所見ありslideのpatchが所見を問わず右側の塊に集まり、所見の切り分けができていなかった。
そこで全体でのクラスタリングは「正常patchを省く」ための大まかなものとして使い、残したpatchだけでコアを作り直して所見との対応を見る。

## 入力

0017 block6_allの出力をそのまま使う（再抽出なし）。
- 評価用patch 161,250（組織割合0.5未満は除外済み）と、その60 run分のk-means割り当て（`eval_labels.npy`）
- 特徴量は0017のキャッシュ（`block6_all_cache/subsets.npz`）から読み、0017と同じPCA64を当て直す

## 1段目: Controlと同じクラスタに入りにくいpatchを抜く

1. 各run（k=50/100/200 × 20）で、各クラスタの評価用patchのうちControl slideのものの割合を出す。
2. patchごとに、自分が入ったクラスタのControl割合を60 runで平均する（Control近さのスコア、低いほどControlから遠い）。
   コンセンサスを取るので、1回のk-meansの揺れには左右されにくい。
3. 閾値: スコアが閾値以下のpatchを残す。閾値ごとに
   - a = 所見ありslide（投与群）のpatchのうち残る割合
   - b = Control slideのpatchのうち残る割合
   を出し、a − b（Youden指数と同じ考え方）が最大になる閾値を採る。比（a/b）は絞るほど大きくなり1 patchで終わるため使わない。
   所見なしの投与群slideは閾値の決定に使わず、残る割合だけを出す。
4. 確認用の出力: スコアの分布（Control / 投与群・所見なし / 投与群・所見あり）、閾値ごとの a・b・a−b、
   用量×時点・試験・scanner・所見ごとの残る割合、t-SNE上のスコア、画像シート（最もControlから遠い / 閾値のすぐ内側 / すぐ外側 / 残ったControl / 捨てられた所見ありslide）。

## 2段目: 残したpatchだけでコアを作る（いろいろ試し、各コアの見た目で決める）

組み合わせ（2 × 2）:
- 埋め込み: 0017のPCA64をそのまま使う / 残したpatchだけでPCA64を学習し直す
- まとめ方: kごとのコンセンサス（k ∈ {10, 20, 40} × 抽出seed 5 × 初期化seed 4、各runは残したpatchの80%で学習し全patchに割り当て、
  kNN 30・τ=0.8・Leiden、50 patch以上かつ3枚以上のslide、0017と同じ） / 1回だけのk-means（同じk）

各組み合わせ・kごとに:
- コアの画像シート（コアの中心に近い順、slideが重ならないよう24 patch）
- コア×所見の表と図（コアのpatchのうち、その所見が記録されたslideのものの割合と、残したpatch全体での割合との比）、コア×試験の図
- 残したpatchのt-SNEをコアで色分け（あわせて試験・scanner・用量で色分け）

## 「取れた」と判断する材料（判断はユーザー）

- 画像シートで、コアが見た目としてまとまっているか
- コアと所見の対応（1つの所見に偏るか）。複数の試験にまたがるか

## 限界・懸念

- 1段目は全体のControl割合で数える。試験・scanner固有の背景がControlと違うものとして残る恐れがある。
  結果で残ったpatchが特定の試験やscanner（SS1598など）に偏っていないかを確認し、偏っていれば「同じ試験のControlとの比較」に切り替える案を出す（2026-10-22ユーザー了承: まずやってみて後から確認）。
- 所見はslide単位の記録。所見ありslideにも正常なpatchが多いので、aは低く出る。
- 1試験・数枚しかない所見（O3参照: Swelling、卵円形細胞増生、好酸性変化（acidophilic）など1試験のもの、1〜2枚の所見）は、
  パイプラインがよくても取れない前提で扱う。取れなくても悲観しない（2026-10-22ユーザー方針）。解析からは除かない。
- PPARα作動薬3つ（WY-14643、fenofibrate、gemfibrozil）が同じ塊にあるため、それらに共通のコアは所見と作用機序を分けられない。
- 試験＝化合物、Controlは1群5枚。
- 1段目のクラスタのControl割合には自分自身も含まれる（クラスタは数百patch以上なので影響は小さい）。

## 所要時間の見込み

1段目は保存済みの割り当てを集計するだけで数分。2段目はk-means 80 run × 2埋め込みとLeidenで数十分、画像シートの読み込みが最も長い（数十分）。
