# 0012: 大規模版でのクラスタリング手法・粒度・seed比較 — 2026-09-29

## 要点

- **個々の候補クラスタはseedを変えると再現しない。** k-meansでは、ある候補クラスタに最もよく重なる別seedの候補クラスタとのJaccardの中央値が、k=2000で0.25〜0.33。ARIも0.26〜0.31。
  一方、候補クラスタに入るpatchの**集合全体**は、seedを変えても約0.72のJaccardで保たれる。
  つまり「どのpatchを候補とみなすか」はおおむね安定しているが、それを個々のクラスタにどう切り分けるかは恣意的に近い。
- **MiniBatchKMeansは同じkのLloydより不安定。** k=2000のARIは0.26対0.31、最良対応Jaccardは0.25対0.33。inertiaもMiniBatchのほうが2〜3%悪い。
  ただし、候補数・保有内率・LOCOはほぼ同じ。部分集合まで変えると、さらに不安定になる（k=2000でARI 0.22）。
- **同じ粒度ならLeidenとコンセンサスのほうが安定している。** 約3000クラスタで、Leiden r=256はARI 0.49、最良対応Jaccard 0.50。k-means k=3000はそれぞれ0.25〜0.29、0.23〜0.29。
  タスク指標は同程度（保有内率中央値0.73〜0.75、LOCO 0.83〜0.84）。
- **どの指標でも「最適なk」は決まらない。**
  - 保有内率の中央値はkとともに単調に上がる（250で0.55、2000で0.70、10000で0.85〜0.89）。ただし保有slideの90%以上が1化合物由来のクラスタが同時に急増する（2000で約40個、10000で650〜900個）ので、この上昇の多くは化合物を識別していることによると考えられる。
  - LOCOはk=1000以降0.84〜0.86で頭打ち。
  - silhouetteは単調に下がる（0.14から-0.05）。明確な山がない。
- **旧cholesterol脂肪変性のpatch（旧42/53）は、どの手法・粒度でも候補にほぼ残らない**（0〜0.2%）。数seedだけ0.1〜0.2まで上がり、これもseedに依存している。
  旧29（Single cell necrosis）と旧81（monocrotaline）は、Lloydのk≥3000とL0のk≥5000で保持が下がる。
- 採用中の0009 k=2000（LOCO 0.859）は、同じ条件でseedを変えた5runの平均0.843より高い側にある。

## 条件

- 0009のembedding cache（3,441枚・PCA64）でクラスタリングし、評価は3,357枚（`analysis_protocol.json`）で行った。
- 候補選定は方式Aで固定。条件はpresence 0、min_compounds 1、q<0.05、Control占有率の95%点<0.001。
- 部分集合: S0〜S4（20万patch、seed 0〜4）、L0（100万patch）。全patchは、部分集合内のkNN15点による多数決で伝播した。
- 手法:
  - MiniBatchKMeans: 0009と同一の設定
  - 全点Lloyd: GPU上、greedy k-means++で初期化
  - Leiden: S0のkNNグラフ
  - Ward: L0上の微小クラスタ2万個の重心に適用
  - コンセンサス: S0上のk-means 60runについて、kNN辺ごとに同じクラスタに入った割合を重みとし、Leidenで切った
- 安定性は3段階で測った:
  - 固定した100万patch標本上のARI
  - 候補patchの集合全体のJaccard
  - 候補クラスタごとの最良対応Jaccardの中央値
- 保有内率は、有意な所見のうち最大のものをslide単位で見た値。patch単位の診断精度ではない。

## 限界

- 評価はすべて同じコーパスでのslide単位のラベル対応であり、独立な検証ではない。形態の目視は未実施。
- Leidenとコンセンサスは最大で約3000クラスタまでしか試していない。5000〜10000の粒度は未比較。
- Wardは重心だけで構築しており、微小クラスタの大きさを重みに入れていない。
- クラスタ作成は、unknown80枚と重複4枚を含む3,441枚で行った。評価からは除外している。
