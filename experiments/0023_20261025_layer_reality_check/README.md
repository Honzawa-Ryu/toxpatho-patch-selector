## 外部（エーザイ・シオノギ、78枚、`external_v1`）

TG-GATEsのアノテーション132枚だけで学習した層（小葉の位置の回帰、0021の形態プロトタイプ）をそのまま当てた（外部では学習・調整なし）。`external_layers.csv`。

- **壊死のプロトタイプ（0021の7・25）の割合**: 対照 0.1〜1.4%、thioacetamide 4〜11%（7→45→130 mg/kgで増える傾向）、acetaminophen 7〜18%、ブロモベンゼン 7〜15%、四塩化炭素 6〜10%、フェニルヒドラジン50 mg/kg 1〜5%。
  企業の記録の「中心静脈側の壊死」がある群で高く、ない群（対照、ストレプトゾトシン、低用量フェニルヒドラジン）で低い。
- **その小葉内の位置**: thioacetamide 0.08〜0.26、ブロモベンゼン 0.11〜0.28、四塩化炭素 0.16〜0.25、acetaminophen 0.15〜0.38（いずれも記録は中心静脈側）。対照のわずかな壊死様patchは 0.12〜0.44。
- 限界: 企業ごとに程度の尺度が違う。エーザイは画像単位。壊死のプロトタイプはTG-GATEsではallyl alcoholに偏っていた（0021）が、外部では化合物を問わず壊死の群で増えた。
