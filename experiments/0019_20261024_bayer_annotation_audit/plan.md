# 0019 Bayerの病変アノテーション（TG-GATEs肝230枚）の中身と信用性の確認

2026-10-24、ユーザーが `data/by-tggates-annotations.zip` を置いた（展開先 `data/by-tggates-annotations/`）。
Bayer AG・Aignosticsの病理医6名が、TG-GATEsのラット肝230枚（57化合物）に壊死・核分裂像などをポリゴンで描いたもの（2023年、CC-BY-SA-2.1-JP）。
使えるようであれば、今後のpatch分類の信用性テスト、または小規模学習用データとして使う（ユーザー方針）。
**この実験は、どんなデータかを可視化して信用性を確かめるところまで**。使い方は結果を見て決める。

## 入力

- `annotations/geojson/*.svs.geojson`（ポリゴン、ラベル、作成者）。座標はlevel 0の画素と想定し、ここで確かめる。
- slideの属性・QCの区分: tggate-wsi-qcの目録（`slide_quality.csv`、230枚すべて含む）
- 病理所見の記録: `data/corrected/open_tggates_pathology.csv`（個体で結びつける。自然発生も区別して持つ）
- svs: 手元にある132枚（`tggate-wsi-qc/data/wsi` と `tggate-bench/data/wsi_all`）

## 出力

1. slide全体への重ね描き（手元の132枚）: 縮小画像にポリゴンをラベルごとの色で重ねる。座標が合っているかの確認を兼ねる。
2. ラベルごとの拡大画像: 各ラベルから、別々のslideのアノテーションを最大24個、20倍で切り出し、ポリゴンの輪郭付きで並べる。
3. 数の確認
   - ラベルごとのslide数・個数・面積、作成者の内訳
   - 所見の記録との突き合わせ: 壊死の面積と記録上の壊死の重症度、核分裂像の数と「核分裂増加」、炎症性浸潤と「細胞浸潤」、単細胞壊死の数と記録
   - 描き漏れの手がかり: 組織のうち「実質」ラベルで覆われた割合
   - 座標の確認: アノテーションの面積のうち、縮小画像で組織と判定された場所に入る割合
4. 表: ポリゴンごと（slide、ラベル、作成者、面積、重心、外接矩形）とslideごとのまとめ

## 限界・注意

- READMEによれば目的は壊死と核分裂像のラベル付けで、他のラベルは学習用の補助。どのラベルも網羅的とは限らず、描かれていない場所を陰性とみなせない。
- アノテーションの9割（15,660件）は1人（pathologist-0）。
- 手元にsvsがあるのは230枚中132枚。画像を使う確認はこの132枚に限る。
- 重なる試験は限られる（block6_cleanとは42枚: gemfibrozil 10、nitrosodiethylamine 10、WY-14643 9、methylene dianiline 5など）。
