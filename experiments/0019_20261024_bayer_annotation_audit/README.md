# 0019 結果まとめ（2026-10-24）

Bayer AG・Aignosticsの病理医によるTG-GATEsラット肝230枚の病変アノテーション（`data/by-tggates-annotations/`、CC-BY-SA-2.1-JP）の中身と信用性の確認。設計は`plan.md`。
出力は`outputs/0019_20261024_bayer_annotation_audit/default/`（gitの管理外）。

## 結果

- 230枚・57化合物・ポリゴン18,171個。手元にsvsがあるのは132枚。block6_clean（0017・0018）と重なるのは42枚（gemfibrozil 10、nitrosodiethylamine 10、WY-14643 9、methylene dianiline 5ほか）。
- **座標は合っている**: ポリゴンの面積の97%（中央値）が組織の上にある。重ね描きでもずれはない。座標はlevel 0の画素。
- **ラベルは見た目と合っている**（`figures/galleries/`）。核分裂像は分裂中の核を細胞1個分で囲む。壊死（面状）は壊死巣を、肝細胞数個分〜1 mm超まで囲む。
- **TG-GATEsの所見記録とよく整合する**（`figures/C2_annotation_vs_record.png`、`annotation_vs_record.csv`）

| 記録上の所見 → ラベル | 記録ありのslideで描かれていた割合 | 記録なしのslideで描かれていた割合 |
|---|---:|---:|
| 壊死 → 壊死（面状） | 97% | 34% |
| 核分裂増加 → 核分裂像 | 100% | 56% |
| 単細胞壊死 → 単細胞の壊死・アポトーシス | 95% | 70% |
| 細胞浸潤 → 炎症性浸潤 | 78% | 51% |
| 胆管増生 → 卵円形細胞・胆管増生 | 24% | 0.5% |

  核分裂像・単細胞壊死の数は、記録の重症度が上がるほど増える。記録なしのslideにも描かれているのは、記録の閾値より軽いものを拾っているためと考えられる。
- **網羅的ではない**: 1枚あたり描かれているのは数か所〜数十か所の小さな領域。「実質」ラベルが組織を覆う割合は中央値0.2%（最大6%）で、正常の例として小さな四角を置いているだけ。
  描かれていない場所を陰性とはみなせない。
- アノテーションの9割（15,660件）は1人（pathologist-0）。

## 使い道の見通し（2026-10-24時点、未決）

- 信用性テスト: 選んだpatchが、壊死・核分裂像・炎症性浸潤・単細胞壊死の上に当たる割合。外れたpatchが正常かは分からないが、「実質」の四角は正常の例に使える。
- 小規模な学習用データ: 病変の切り出しと、実質・中心静脈・門脈域・血管の切り出し。57化合物にまたがる。
