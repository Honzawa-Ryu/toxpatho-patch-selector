- **A をすべての評価で上回る表現はなかった。**
- **β は「ラベルあり ↔ ラベルなし」のつまみ**として一貫して効く。β=0.5 → B に近づき、β=4 → C に近づく。β=2 は (a) F1 が +0.056 [0.043, 0.072] で C と同水準に上がり、(b) は −0.033 [−0.072, 0.005]（区間内）、名前付き AUC は −0.049 [−0.099, −0.003]。
- **白色化を 128 次元にすると脂肪変性の分離が最良**（A128: 12 / 5、程度との相関 CCl4 0.89・cholesterol 0.92）。名前付き AUC は A と同じ（差 +0.001）。(a) は −0.022 [−0.038, −0.007]、(b) は −0.025 [−0.072, 0.016]。
- **LDA を PLS-DA・NCA に替えるのは逆効果**。出力次元を増やしても (b) は上がらず、名前付きプロトタイプの AUC が大きく落ちる（P32 −0.10、P64 −0.18、N32 −0.19）。「LDA は次元を落としすぎる」という懸念に対しては、LDA を替えるより元の表現（Sphering）を並べる方が有効だった。
- 所見別（`unseen_finding_classification.csv`）: 壊死の読み出しは LDA の重みに強く依存（A 0.51、β2 0.68、β4 0.78、C 0.77）。胆管増生は A 0.75 が最良。好酸性変化はどれも 0.52 以下。

## 読み

- 単一の表現で①と②を両取りするなら **A_beta2**（F1 は C 並み、ラベルなしは A の区間内）。
- ②（ラベルなし所見・脂肪変性）を優先するなら **A（β=1）または A128**。A128 は脂肪変性の細分化（CCl4 と cholesterol 食）に最も向く。
