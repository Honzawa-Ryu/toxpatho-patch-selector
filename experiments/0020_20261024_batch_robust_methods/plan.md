# 0020 バッチ効果に頑健な表現の比較と、patchのプロトタイプ作り

プロジェクトの方向（`../DISCUSSION_20261024_batch_robust_direction.md`）を受け、2026-10-24ユーザー依頼:
「可能な限り様々な手法を試して有効性を検証し、有用そうなものでTG-GATEs（さらに外部データも含めて）patchのプロトタイプを作る。評価にはBayerのアノテーション（0019）を使う」。

## 評価データ

- Bayerのアノテーションがあり、Macenko正規化・全patchのUNI2-h特徴量（0016）があるslide。最初は61枚、0016の`full_annot`段で71枚を足して最大132枚。
- patchのラベル: patch（20倍・256px）とポリゴンの重なりが、小さい方の面積の50%以上なら、そのラベルを付ける。複数なら優先順（病変 > 構造 > 実質）。
  ラベル: 実質（正常）、中心静脈、門脈域、大きな血管、壊死（面状）、炎症性浸潤、核分裂像、単細胞壊死（2つのラベルを統合）、髄外造血、出血、濃い肝細胞、アーチファクト。
- ラベルのないpatchも1枚あたり800個無作為に入れる（バッチの混ざり具合と、クラスタリングの土台）。描かれていない場所を陰性とはみなさない。

## 指標（単一細胞のバッチ統合の評価の考え方: 混ざり具合 × 区別の保存）

- 区別の保存（高いほどよい）
  - 別のslideだけを近傍にしたkNN（k=15）で、ラベル付きpatchのラベルを当てる。クラスごとの再現率と、その平均（balanced accuracy）。別の試験だけを近傍にした版も出す。
  - k-means（k=30）のクラスタとラベルの対応（NMI、ラベルごとの最多クラスタへの集中度）
- 混ざり具合（高いほどよい）
  - 全patchのkNN（k=30）のうち、別のslideから来る割合と、別の試験から来る割合

## 手法（まず学習なし）

| 名前 | 内容 |
|---|---|
| raw | UNI2-h（L2正規化、1536次元） |
| pca64 | 全体のPCA64 |
| center_slide | slideの平均（全patch）を引く |
| zscore_slide | slideごとに次元ごとの平均・標準偏差でそろえる |
| rank_slide | slideごとに次元ごとの順位を正規分布の分位点に置き換える |
| center_stripe | slide×スキャナのストライプ（幅2,032 px）ごとの平均を引く |
| coral_slide | PCA64の空間で、slideごとの共分散を白色化して全体の共分散に合わせる |
| harmony_slide / harmony_exp | PCA64にHarmony（自前の実装）。バッチ = slide / 試験 |
| center_harmony | slideの平均を引いたPCA64にHarmony（バッチ = slide） |
| mnn_contrast | 別slideとの相互最近傍の組（slideの平均を引いた空間で探す）を正例に、生の特徴量から64次元への射影を対照学習（学習あり、ラベルは使わない） |
| bbknn_slide | 近傍をslideごとに同数ずつ取るグラフ（kNNの評価のみ） |

学習ありの手法（固定したUNI2-hの上の射影層: slide内の近傍・slideをまたぐ相互最近傍を正例にした対照学習、ドメイン敵対など）は、学習なしの結果を見て次の段で足す。

## プロトタイプ（次の段）

良い表現でTG-GATEsのpatchをクラスタに分け、各クラスタの代表patch（プロトタイプ）を作る。Bayerのラベルとの対応と画像シートで確かめる。外部データはユーザーに確認してから。

## 限界

- アノテーションは網羅的ではなく、9割は1人の病理医。ラベルの無いpatchを陰性とみなさない。
- 評価用slideは試験が偏る（methylene dianiline、gemfibrozil、WY-14643、nitrosodiethylamineなど）。
- slide単位の補正は、slide全体が変わるびまん性の変化も消しうる。
