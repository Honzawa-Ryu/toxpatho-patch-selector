# 0011: 候補選定条件の比較とパッチ一覧

## 目的・判断

大規模化で旧来の形態が消えたのか、候補の選定条件で落ちたのかを分けて確認する。k=2000 の割当は固定し、選定だけを変更した探索的比較。従来の本番設定は置換しない。

- 実験・時点内の投与群対Control比較で、旧 fatty change 候補につながる **1356 / 846 / 703 / 535** を4つとも回収した。
- Controlの希少性まで化合物内で判定すると別の有望候補を失う。その条件を全体Controlに戻したB2も比較した。
- B2でも旧29・81由来のパッチに取りこぼしがある。全面置換できる結果ではない。
- 組織割合フィルタは維持する方針。代表的な背景候補95・1425を除き、上記4候補は維持できる。24パッチ推定なので全クラスタについて完全な保証ではない。

## 比較条件

3357スライド・44化合物。元3441スライドからメタデータ不明80枚と同一動物の重複画像4枚を除外。パッチを独立した検定標本とは扱わず、スライドごとのクラスタ占有率を使用。

|方式|投与群とControlの比較|Control占有率95百分位 < 0.001 の参照範囲|
|---|---|---|
|A|全体でMann–Whitney U、2000検定のBH補正|全体|
|B1|化合物ごとにexperiment・時点で層別した順位和検定|当該化合物|
|B2|B1と同じ|全体（従来条件を維持）|

B1/B2は片側正規近似、同順位補正あり、層重み1/(n+1)。全44×2000=88000検定をまとめてBH補正しq<0.05。各層に投与・Controlがそれぞれ2枚以上必要。投与doseはまとめて比較。クラスタ保有は占有率>0.001。効果量は保有率差と順位効果量を計算し表示・並べ替えに使い、事後的な効果量閾値は導入していない。

所見との対応は共通の全2000クラスタ×36所見で計算。表示する「所見との保有内率」は、そのクラスタを保有するスライドのうち関連所見ラベルを持つ割合。最も対応する所見を事後選択した値で、パッチ診断精度ではない。

## 限界と次の判断

これは既知の旧候補を参照した事後的な探索。施設差は未調整。化合物内の投与差が出ることだけでは、所見特異性や複数化合物での再現を証明しない。少数Controlの正規近似検定は独立検証前の候補探索として扱う。

代表12クラスタの一覧画像と1356の拡大像を目視確認した。空胞の多い像や背景の多い像は見分けられるが、所見名の確定や全489クラスタの評価はしていない。まず4つの回収候補と539/931、失われる585/45を確認し、レビュー結果を記録する。従来候補を維持したうえで追加採用を検討し、独立した複数compound/experimentの評価subsetで検証する。
