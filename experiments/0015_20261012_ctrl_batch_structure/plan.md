# 0015 無所見Ctrlで試験間差を評価する

議論メモ（[DISCUSSION_20261012](../DISCUSSION_20261012_next_experiments.md)）の「最初の実験」。
全試験の無所見Ctrlをまとめてクラスタリングし、正常背景が試験間で共有されるか、
特定の試験・scannerに偏るクラスタがあるかを見る。結果は小規模poolの選定に使う。

## 目的

- 後段の候補選定は「Controlにほぼ出ないクラスタ」を拾う。Ctrl段階で試験固有のクラスタがあると、
  他試験から見て「Controlにないクラスタ」に見え、偽の候補になりうる。その量と正体を先に把握する。
- 試験差が、個体差・時点差と比べてどの程度大きいかを測る。

## 対象

- `0010/label_audit/manifest_known_unique.parquet` のうち Control かつ記録上無所見: 830枚、44 exp_id、174群（化合物×時点）。
- scannerは `0010/label_audit/slide_scanner_meta.csv` で対応を取る。
- 群ごとの実枚数は5枚147群・4枚20群・3枚以下7群。3枚以下の群は群内差の推定から外さず、枚数を併記する。

## 条件（2026-10-12 ユーザー確認済み）

| 項目 | 設定 |
|---|---|
| 特徴量 | 0009の `embedding_cache`（全3,441枚で学習したPCA64）をそのまま使う |
| 学習patch | 1枚あたり512 patchを無作為抽出（830枚 × 512 ≒ 42.5万） |
| 時点 | 4時点まとめて1回のクラスタリング |
| 手法 | k-means（`lib.clustering.kmeans_lloyd`、GPU） |
| k | 50, 100 |
| run数 | 学習patch抽出seed 0〜4 × 初期化seed 0〜3 = kごとに20 run（計40 run）。**seed数は提案。下記参照** |
| 割当 | 対象830枚の全patchを最近傍重心に割り当て、slide別占有率を出す |

seedを「抽出」と「初期化」に分けるのは、議論メモの「seedのみの変更と学習patch抽出の変更を区別」に従うため。
所要時間の見込み: 1 runはLloydが数十秒、全patch（約1,300万）の割当が数十秒〜数分。埋め込みの読み込みは1回で全runに共有する。
1ジョブで40 run、1時間以内の見込み。初回の実測で速ければseedを増やす（ユーザー了承済みの方針）。

## 見るもの

すべてslide単位で集計する。patchを独立な検定単位にしない。

- **a. slide別占有率**: slide × クラスタの割合表。以下の土台。
- **b. 4段階の距離比較**: slide占有率間の距離（Jensen–Shannon距離を予定）を、次の4段階で比べる。
  1. 同試験・同時点（個体差）
  2. 同試験・別時点（時点差）
  3. 別試験・同時点（試験差）
  4. 別試験・別時点
  3が2より明らかに大きければ「試験差が時点差より強い」。検定はslideのラベル並べ替え（試験ラベルを時点内で入れ替える）で行う。
- **c. 試験に偏るクラスタ**: クラスタごとに、占有の何割が上位1試験・上位3試験から来るか、
  何試験で80%に達するかを出す。偏りの強い順に、複数slideから取ったpatchの画像シートを作る（判断はユーザーの目視）。
  偏りが強いだけで不適切とはしない。
- **d. scanner比較（付け足し）**: scanner混在の群の中で、別scanner同士と同scanner同士の距離を比べる。
  scannerに偏るクラスタも数える。枚数が少ないため参考扱い。
  0015の対象（無所見Ctrl）に限ったときの混在群の数は実行時に数え直す（39群は全3,357枚での数）。
- **e. seed・kをまたいだ安定性**: bの外れ試験、cで偏りの強い試験が、run・kをまたいで同じかを数える。クラスタIDの一致は求めない。
- **f. クラスタを使わない確認（付け足し）**: slide平均埋め込みで b と同じ比較をする。

## 成果物

- 対象slide一覧（scanner付き）
- run別のslide占有率（parquet）、run設定
- b・d・f の距離分布の図と表、並べ替え検定の結果
- c の偏り指標の表（runごと・run集約）と、偏り上位クラスタの画像シート
- e の集約表（試験ごとに「外れ」「偏り上位」に入ったrunの割合）

## 決めていないこと

- 「大部分が共有されている」と判断する基準。結果を見てから議論する。
- 試験を除外するかどうかと、その基準。0015では除外しない。
- 画像シートに載せるクラスタ数と1行あたりの枚数（0014と同じ1行6枚・同一slideから1枚までを予定）。

## 追加: 染色正規化の有無の比較（2026-10-13 ユーザー確認済み）

初回run（variant `main`）は0009の埋め込みで、**染色正規化なし**だった。正規化済み特徴量は0005の219枚にしかないため、
その中の無所見Ctrl（157枚・8化合物・32群）に限って、正規化の有無だけを変えた2条件を回す。

| variant | 特徴量 | PCA |
|---|---|---|
| `s219_raw` | 0001のTRIDENT出力（正規化なし） | 対象157枚で学習（L2正規化後、1枚512 patch、seed 0） |
| `s219_macenko` | 0005のMacenko正規化版 | 同上 |

クラスタリング・評価の条件は`main`と同じ。比較するのは`s219_raw`と`s219_macenko`の間で、`main`とはPCAの学習範囲が違う。
8化合物のみで、scanner混在の群はほぼない見込み。以後の実験では染色正規化を基本必須とする（ユーザー方針）。
