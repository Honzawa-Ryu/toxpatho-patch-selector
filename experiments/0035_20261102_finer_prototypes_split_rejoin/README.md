## 読み

- **Bayer のラベル（小さな対象が多い）では、細かくしても coverage はほぼ上がらない。** k を 100 → 1000 にしても 0.17 → 0.18。上がるのは split_label（0.23）だけで、ラベルを使う方法。純度の高いプロトタイプに入った patch の適合率は 0.8〜0.9 で、held-out でも保たれるので、問題は純度ではなく「ラベルの patch が純度の高い塊に集まらない」こと。
- **脂肪変性（強い所見）では、細かくすると純度と coverage が両方上がる。** 全集合での最良 share は k=100 の 0.48 から k=1000 の 0.93、split_record の 0.96 に。化合物内で純度 0.9 以上のプロトタイプに入る脂肪変性 slide の patch の割合は 0 から 0.4〜0.5 に。
- **ラベルを使わない方法のうち、split_record（記録で分ける）は脂肪変性に効き、split_dispersion（距離で分ける）は効かない。** 記録の手がかりがあれば②向けに使える。
- **Ward のつなぎ直し**は、同じ数の flat と同程度（guided_label は plain とほぼ同じ）。guided_record は A128 で脂肪変性の coverage が最良（100 クラスタで 0.54）だが A では低く、表現によって変わる。
- (b) のラベルなし AUC は k=200 前後で 0.77〜0.79（k=100 の 0.72 より高い）。クラスタ数が増えると説明変数が増えるので参考値。

## 注意

- 全集合の「記録の coverage」（`record_purity.csv`、`F2_record_coverage.png`）は、分母が記録あり slide の全 patch（正常な部分を含む）なので、上限は所見の広がりで決まり、所見間で比べられない。脂肪変性以外は最大でも 0.14（細胞浸潤、k=1000）。
- 脂肪変性の「純度」は slide の記録で見たもの。patch が本当に脂肪変性かは目視していない。
- seed は 1 つ。k=1000 のコンセンサスは 5 回。
- 割り当て（`assign_*.npy`、全 patch、26 通り）を保存した。地図やタイルを作れる。

## 目視（2026-11-02、`scripts/fatty_prototype_sheets.py`、`scripts/fatty_prototype_maps_full.py`）

A128 の split_record と flat k=1000 について、化合物内の純度 0.9 以上のプロトタイプのタイル（`v1/tiles/`）と、slide の全 patch を 1 近傍で補間した地図（`v1/maps_full/`）を作った。一覧は `v1/fatty_pure_prototypes.csv`。

- CCl4 側（6 個、ほぼ exp 67 の 29 日反復）は見た目が 3 種類: 大滴性（p0667・p0750）、小滴性（p0416・p0417）、空胞の目立たない淡い細胞質（p0330・p0647）。
- cholesterol 食側（4 個、exp 698 高用量、記録は Peripheral）は小滴性の泡沫状（p0661・p0113・p0668）と、空胞の目立たない淡い細胞質（p0193）。
- 同じ「脂肪変性」の記録でも CCl4 と cholesterol 食は別のプロトタイプに分かれ、CCl4 の中でも大滴と小滴が別になる。
- 地図: CCl4（26526、grade 3、Centrilobular）では純プロトタイプの patch が小葉単位の網目状に並び、原画像の淡い部分（小葉中心）と一致する。cholesterol 食（66207、grade 4、Peripheral）では全体に広がり、grade 4 では帯状の分布は読めない。
- 空胞の目立たないプロトタイプ（p0330・p0647・p0193）が純度 0.97 以上で入るのは、純度が slide 単位の記録で決まるため。病変の周りの実質を拾っている可能性がある。

- どの所見でも、対照群とは化合物を伏せて AUC 0.84〜1.00 で分かれる。B128（ラベルなし）でもほぼ同じ（`overview.csv`）。
- **ただし、所見ごとに選ばれたプロトタイプは大きく重なる**（Jaccard 0.22〜0.72、多くは 0.4〜0.55）。選ばれたプロトタイプの多くは「投与された slide に増える変化全般」で、所見に特有ではない。肥大と好酸性変化の重なり 0.72 は最も大きい（同じ化合物・小葉中心性の変化が並んで記録されることが多い）。

- 化合物数が少ない所見（3〜4）は、化合物をまたぐとは言えない。

### 次

- 所見に特有のプロトタイプを選ぶ: 対照群ではなく、同じ試験の記録のない投与群と比べて増えるものを選ぶ。全所見で共通に増える「投与全般」のプロトタイプを除く。

## 対照群だけで試験を当てられるか（2026-11-05、`scripts/control_study_identification.py`）

ユーザーの問い: 対照群だけを複数の試験・化合物で用意し、所見と同じ条件で当てられるなら、プロトタイプに試験間差が残っている。
対照群が 6 枚以上ある 46 試験（45 化合物）の対照群 920 枚。slide 単位の 5 分割で、学習側の slide から「その試験の対照群で 2 倍以上多いプロトタイプ」を選び（所見と同じ基準）、伏せた slide でその割合から「その試験の対照群か」を判別した。`control_study_identification/`。

| 表現 | 試験ごとの AUC の中央値 [四分位] | AUC 0.8 以上の試験 | 最もスコアの高い試験を予測にしたときの正解率（偶然 2%） |
|---|---:|---:|---:|
| A128、split_record | 0.86 [0.81, 0.91] | 78% | 9% |
| B128、split_record | 0.84 [0.79, 0.87] | 72% | 9% |
| A128、k=1000 | 0.89 [0.84, 0.92] | 89% | 17% |

- **プロトタイプの構成には試験間差がはっきり残る。** 対照群どうしでも、試験ごとに AUC 0.84〜0.89 で見分けられる。スキャナ（2 台、試験にほぼ入れ子）でも AUC 0.82〜0.86。
- この大きさは、所見の slide と対照群を見分けた AUC（0.84〜1.00）と同じ水準。したがって「所見の slide と対照群が分かれる」だけでは、所見を拾った証拠として弱い。
- 所見の解析では、同じ試験の対照群の平均を引き、化合物を伏せて評価しているので、試験全体にかかる差はそのまま当たりにはならない。それでも、所見に特有かどうかは「同じ試験の記録のない投与群と」の比較で示す必要がある（細胞浸潤 0.58、核分裂増加 0.69、空胞化 0.69 は弱い）。
- 注意: ここでは slide 単位で分けているので、伏せた slide の試験は学習側にも出てくる（試験ごとの特徴があるかを見る設定）。
