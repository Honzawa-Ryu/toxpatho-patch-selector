## 読み

- **Bayer のラベル（小さな対象が多い）では、細かくしても coverage はほぼ上がらない。** k を 100 → 1000 にしても 0.17 → 0.18。上がるのは split_label（0.23）だけで、ラベルを使う方法。純度の高いプロトタイプに入った patch の適合率は 0.8〜0.9 で、held-out でも保たれるので、問題は純度ではなく「ラベルの patch が純度の高い塊に集まらない」こと。
- **脂肪変性（強い所見）では、細かくすると純度と coverage が両方上がる。** 全集合での最良 share は k=100 の 0.48 から k=1000 の 0.93、split_record の 0.96 に。化合物内で純度 0.9 以上のプロトタイプに入る脂肪変性 slide の patch の割合は 0 から 0.4〜0.5 に。
- **ラベルを使わない方法のうち、split_record（記録で分ける）は脂肪変性に効き、split_dispersion（距離で分ける）は効かない。** 記録の手がかりがあれば②向けに使える。
- **Ward のつなぎ直し**は、同じ数の flat と同程度（guided_label は plain とほぼ同じ）。guided_record は A128 で脂肪変性の coverage が最良（100 クラスタで 0.54）だが A では低く、表現によって変わる。
- (b) のラベルなし AUC は k=200 前後で 0.77〜0.79（k=100 の 0.72 より高い）。クラスタ数が増えると説明変数が増えるので参考値。

## 注意

- 全集合の「記録の coverage」（`record_purity.csv`、`F2_record_coverage.png`）は、分母が記録あり slide の全 patch（正常な部分を含む）なので、上限は所見の広がりで決まり、所見間で比べられない。脂肪変性以外は最大でも 0.14（細胞浸潤、k=1000）。
- 脂肪変性の「純度」は slide の記録で見たもの。patch が本当に脂肪変性かは目視していない。
- seed は 1 つ。k=1000 のコンセンサスは 5 回。
- 割り当て（`assign_*.npy`、全 patch、26 通り）を保存した。地図やタイルを作れる。
