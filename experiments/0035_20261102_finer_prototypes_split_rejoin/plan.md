# 0035 計画（2026-11-02）

## 問い

プロトタイプの純度が実用に足りない（0027 の伏せたラベルの純度 0.1〜0.5、伏せなくても同程度）。純度を上げる 2 つの案をユーザーが提示した。

1. 階層を増やす。純度が一定以下のクラスタだけを再クラスタリングする。
2. k を増やして系統樹を作り、つなぎ直す。

両方を入れる。データも他の試験を入れ、脂肪変性（強い所見）を他の所見と一緒に相対化する（2026-11-02 ユーザー）。

## 集合

Bayer 230 枚（全 patch、325 万）＋脂肪変性 3 試験 188 枚（各 2,048 patch）＋0033 の未学習 3,319 枚（各 2,048 patch、保存した PCA256）。合計 3,737 枚、約 1,040 万 patch。
記録は TG-GATEs の病理所見（11 所見: 0030 の 10 所見＋脂肪変性）を全 slide について持つ。脂肪変性の記録ありは 87 枚で、すべて 3 試験の中。

## 表現

A（Sphering 64 ‖ LDA 13）と A128（Sphering 128 ‖ LDA 13）。作り方は 0033・0034 と同じ。k-means の学習点は Bayer と他の試験から 60 万ずつ。

## 方法（表現ごとに 13 通り）

| 方法 | 中身 |
|---|---|
| flat_k100 / 200 / 500 / 1000 | コンセンサス k-means |
| split_label | flat k=100 から、Bayer の学習ラベルの最多割合が 0.8 未満のクラスタ（ラベル付き patch 50 以上、patch 2,000 以上）を 5 つに分ける。2 回 |
| split_record | 同じ手順で、基準は slide の記録。倍率 2 以上に濃縮された所見があり、その記録ありの slide 由来の割合が 0.8 未満のクラスタを分ける |
| split_dispersion | 同じ手順で、基準は重心からの平均距離が上位 30% のクラスタ（ラベルなし） |
| tree1000_plain_100 / 200 | flat k=1000 の葉を Ward 法（重心と大きさ）で 100 または 200 までつなぐ |
| tree1000_guided_label_100 / 200 | つなぐ条件: 両方の最多ラベルが同じ（ラベル付き patch 50 未満の葉は不明として何とでもつなぐ） |
| tree1000_guided_record_100 / 200 | つなぐ条件: 両方の最多記録所見（倍率 2 以上）が同じ。濃縮のない葉どうしはつなぐ |

split と tree の条件つきつなぎ直しは、ラベルか記録を使う。②の場面（ラベルなし）で使えるのは record と dispersion。

## 評価

1. (a) held-out。Bayer 230 枚を化合物単位で 5 分割し、LDA・クラスタ・名前付けは学習側だけで行う。ラベルごとに F1 と、学習側の適合率 0.8 以上のプロトタイプに入った評価側 patch の割合（coverage）、その patch の適合率。実質を除く 13 ラベルの macro。化合物の復元抽出で区間。
2. (b) 未学習 3,319 枚の読み出し AUC（0033 と同じ。クラスタ数が増えると説明変数が増えるので参考）。
3. (c) 記録の純度（全 3,737 枚）。所見ごとに、プロトタイプの patch のうち記録ありの slide 由来の割合（share）の最大、基準率に対する倍率、share 0.8 以上のプロトタイプに入る記録あり slide の patch の割合（coverage）。脂肪変性は 0026 と同じ化合物内の純度も出す。

## 判断の基準

- flat で k を上げたとき、coverage（純度 0.8 以上に入る割合）が上がるか、それとも散らばるだけか。
- split と tree が、同じクラスタ数の flat より coverage を上げるか。
- ラベルを使わない方法（split_dispersion、split_record、tree_guided_record）で、ラベルを使う方法にどこまで近づくか。これが②で使える手。

## 注意

- 純度だけでは細かい k が必ず勝つので、coverage で見る。
- 記録の純度は slide の記録で見たもので、patch が本当にその所見かは目視していない。
- seed は 1 つ。k=1000 のコンセンサスは 5 回。
- 所要時間の見込み 3 時間（held-out 5 分割 × 2 表現 × 13 方法、k=1000 の k-means が主）。
