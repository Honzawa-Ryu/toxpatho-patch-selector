# 0017 塊内でのコンセンサスによるpatch pattern発見（パイロット）

系列A（Issue #5）の最初の実験。系列C（0015）で、反復投与の全Controlを背景の近さで6つの塊に分けた（cut 0.72）。
最大の塊（44試験）のうち、手元に投与群がある13試験で、k-meansを複数回回し、繰り返し同じクラスタに入るpatch群（コア）を取り出す。
**目的は「そういうpatternが取れるか」の判断**。候補選定（q値・投票率）や拡大は扱わない。

## 対象

0016 full段の出力（Macenko正規化、全patch、参照は全Controlから推定）。13試験・1,020枚（Control 260、投与群760、うち所見あり452）。

| 試験（化合物） | |
|---|---|
| WY-14643、gemfibrozil、fenofibrate | PPARα作動薬3つ |
| ethinylestradiol、amitriptyline、diltiazem、lornoxicam、ticlopidine、phenacetin、bucetin | |
| acetamidofluorene、nitrosodiethylamine、methylene dianiline | |

主な所見（投与群のslide数）: Hypertrophy 180、顆粒状好酸性変性 136、胆管増生 88、壊死 86、Swelling 60、核分裂増加 50、好酸性変化 50、細胞浸潤 49、卵円形細胞増生 49、細胞質空胞化 48。
ラベルは`0010/label_audit/manifest_known_unique.parquet`（13試験の1,020枚はすべて記録あり）。

## 手順

1. **前処理**: L2正規化 → PCA64。PCAはControlと投与群から同数のpatchで学習する（0003の注意: Controlだけで学習すると所見方向が消える）。
2. **複数run**: 学習patch（1枚あたり200 patch、計約20万）にk-means（`lib.clustering.kmeans_lloyd`）。
   - 変える条件: k ∈ {50, 100, 200} × 学習patch抽出seed 0〜4 × 初期化seed 0〜3 = 60 run。
   - 3つの条件はrunごとに記録し、混ぜて集計したものとkごとの集計を両方出す。
3. **評価用patch**: 1枚あたり50 patchを固定（計約5.1万）。各runの重心で割り当てる。
4. **共所属グラフ**: 評価用patchの埋め込み空間でのkNNグラフ（各patch 30近傍）を作り、各辺に「同じクラスタに入ったrunの割合（共所属率）」を付ける。
   全patch対は数えない（5.1万²は大きすぎる）。近傍の対だけを見る。
5. **コアの抽出**: 共所属率がτ以上の辺だけを残し、連結成分（またはLeiden）でまとまりを取る。
   - 大きさ50 patch以上・3枚以上のslideにまたがるものだけをコアとし、残りは「未割当」。
   - τ = 0.7 / 0.8 / 0.9で比べ、コア数・未割当率の変化を出す。
6. **コアの安定性**: 60 runを無作為に半分ずつに分けてそれぞれでコアを作り、対応するコアのpatch重なり（Jaccard）を見る。これを数回繰り返す。

## 出力

- コアの一覧: 大きさ、slide数、試験数、Controlの割合、用量・時点・scannerの内訳、slideの所見ラベルとの対応（保有slideでの所見の割合）
- コアごとの画像シート: 中心性（コア内の平均共所属率）の高い順に、別々のslideから24 patch。出どころ（試験・用量・scanner）を併記
- 未割当patchの割合と、その画像例
- τごとの比較、半分ずつのrunで作ったコアの一致度
- 各runの重心（後で他のslideを同じ物差しで割り当てるため）

## 「取れた」と判断する材料（判断はユーザー）

- (a) 一定数のコアがあり、評価用patchの一定割合を覆う
- (b) 画像シートで、各コアが見た目としてまとまっている（ユーザーの目視）
- (c) runを分けても同じコアが出る
- (d) Controlにほぼ出ないコアと、Controlにも出るコア（正常背景）が分かれる

## 所要時間の見込み

PCAとrunはGPUで数十分。評価用patchの読み込みとkNNグラフで数十分。画像シート作りが最も時間がかかる（コア数×24 patchの読み込み）。合計1〜2時間の見込み。

## 限界

- 塊内でも試験間差は残る（0015で塊内の試験間距離は試験内とほぼ同程度だが、ゼロではない）。コアが1試験に集中していれば試験の背景を拾っている可能性がある。コアごとに試験数を必ず出す。
- 試験＝化合物。PPARα作動薬3つが同じ塊にあるため、それらに共通のコアは「所見」と「作用機序」を分けられない。
- 所見はslide単位の記録。patchが所見を写しているとは限らない。
- 空白に近いpatchやぼけたpatch（SS1598の縞、SS1224）がコアを作る可能性がある。画像で確認する。

## 決めていないこと

- τとコアの最小サイズは上の値で始め、結果を見て決める。
- コアの抽出は連結成分とLeidenの両方を出す（2026-10-16ユーザー了承、結果を見て改良を検討）。
- 空白patchの除外（2026-10-16ユーザー了承「時間次第でできれば」）: 評価用patchだけ、低解像度の層から読んで白に近くない画素の割合を出し、0.5未満を除く。
  k-meansの学習patchは除かない（全patchの画素を読むと時間がかかるため）。除いた数はresults.jsonに記録。
- pattern登録の基準・保存形式（0017の結果を見てから）。
