# 階層性を持ったプロトタイプの方向性（相談用、2026-11-03）

他のモデル・研究者と相談するためのまとめ。前提を知らない読み手でも読めるように書いた。数値は各実験の README・出力から引いた。

## 1. 目的

毒性病理の全スライド画像（WSI）の patch を、データから「プロトタイプ」（似た見た目の patch のまとまり）に分け、所見や正常構造に対応させたい。最終的には、所見の代表 patch を取り出し、病理の記録にない細かい違い（例: 同じ「脂肪変性」の中の大滴と小滴）まで分けることを狙っている。

## 2. データ

- Open TG-GATEs のラット肝 WSI。試験（化合物）ごとに染色・スキャン条件が違い、試験と化合物がほぼ一対一で重なる（バッチ＝化合物）。スキャナは 2 台で、試験にほぼ入れ子。
- 病理の記録は slide（個体）単位。所見名と程度（minimal〜severe）、部位（小葉中心性・辺縁性など）がある。patch 単位の正解はない。
- Bayer AG/Aignostics が公開した 230 枚のポリゴン注釈（14 ラベル: 壊死、核分裂像、炎症性浸潤、中心静脈、門脈域など）。座標とラベルは信用できるが網羅的ではない。脂肪変性のラベルはない。
- 今の解析の集合: 3,737 枚（101 試験）、約 1,040 万 patch。内訳は Bayer の 230 枚（全 patch）、脂肪変性の 3 試験 188 枚（CCl4 の 2 試験と cholesterol 食の 1 試験）、学習に使っていない 3,319 枚（43 試験）。後の 2 つは各 slide 2,048 patch に間引いている。

## 3. 今のパイプライン（すべて 20 倍の patch 単体）

1. 20 倍・256 画素の patch を切り出し、Macenko 法で染色を正規化し、病理基盤モデル UNI2-h で特徴量（1,536 次元）を得る。
2. 試験間差を抑えるため、特徴量の各次元を slide 内の順位に変換し、PCA で 256 次元に圧縮する。
3. 試験ごとに、その試験の対照群の patch の平均と共分散で白色化する（Sphering）。上位 64 または 128 次元を使う。
4. 必要に応じて、Bayer のラベルで学んだ線形判別分析（LDA、13 次元）を横に並べる（「A128」= 白色化 128 次元 ‖ LDA 13 次元）。
5. k-means（コンセンサス）でプロトタイプを作る。k=100〜1000。純度の低いクラスタだけを、病理記録を手がかりに再分割する方法（split_record）も試した。

## 4. ここまでに分かったこと

**試験間差の除去**
- 対照群 857 枚で、近傍 30 個のうち別の試験の patch の割合は、順位変換前 0.73 → 順位変換 0.84 → ＋LDA 0.95（完全に混ざれば 0.98）。大きく減ったが、同じ試験の近傍は期待値の 2〜4 倍がすべての試験に薄く残る。

**ラベルのある所見（Bayer のラベル）**
- 化合物単位の held-out で、LDA を入れると F1 が上がる（実質を除く macro F1: LDA なし 0.26〜0.31、LDA あり 0.37〜0.44）。
- ただし、純度の高いプロトタイプに入るラベルの patch は全体の 13〜23% にとどまり、k を 100 から 1000 に増やしても変わらない。純度の高いプロトタイプに入った patch の適合率は 0.8〜0.9 で、問題は「ラベルの patch が純度の高い塊に集まらない」こと。
- 取れているのは壊死、核分裂像、太い血管、濃い肝細胞など。単細胞壊死、炎症性浸潤、髄外造血、出血は取れていない（patch より小さい対象）。

**ラベルのない所見**
- 脂肪変性は、クラスタを細かくすると純度と網羅率がともに上がる。化合物内で純度 0.9 以上のプロトタイプに入る脂肪変性 slide の patch は 0 → 0.4〜0.5。
- 目視では、同じ「脂肪変性」の記録でも CCl4 と cholesterol 食は別のプロトタイプに分かれ、CCl4 の中で大滴と小滴が別になった。CCl4 の地図では小葉中心の網目状に並んだ。
- LDA を外しても脂肪変性の分け方はほぼ同じ。分けている主因は白色化（とその次元）で、LDA はラベルのある所見にだけ効く。
- 肥大（AUC 0.73〜0.80）、好酸性変化（0.38〜0.60）のように slide 全体に広がる変化は、どの表現でも取れない。slide 内の順位に変換した時点で消えている可能性が高い。

**未解決**
- 名前付け: 記録（slide 単位）では大滴・小滴・空胞の目立たないものが全部「脂肪変性」になり、Bayer には脂肪のラベルがない。
- プロトタイプの系統樹: 重心の Ward 法、分割の履歴、patch の近傍のつながり、記録の構成の 4 通りで作ったが、隣り合うプロトタイプが見た目で似ているとは言いにくい。
- 正味の slide 枚数（1/Σp²）が少ないプロトタイプ（1〜2 枚の slide にしか出ない）は除く方針（閾値は未決）。

## 5. なぜ階層性か

今の表現は 20 倍・約 128 µm 四方の patch 単体で、周囲を見ていない。毒性病理の判断は周囲の構造に依存する。

- 小葉の中の位置（中心静脈の周りか、門脈域の周りか）は所見の定義に入る（脂肪変性の小葉中心性と辺縁性、肝細胞肥大の分布）。
- slide 全体に広がる変化（肥大、好酸性変化）は、patch 単体では対照群と区別しにくい。より広い範囲を見れば、分布や密度の違いとして見える可能性がある。
- patch より小さい対象（単細胞壊死、炎症細胞の小さな巣）は逆に、より高い倍率が要る可能性がある。

参考: Li L, Shelton L, Forest T, et al. "Unsupervised Anomaly Detection on Preclinical Liver H&E Whole Slide Images using Graph based Feature Distillation." MICCAI 2025（GraphTox）。ラット肝 WSI で、5×・10×・20× を組み合わせ、patch 間の空間関係をグラフにし、正常組織だけで学んだ Feature Distillation の誤差から異常を検出する。非グラフ型の最良手法より AUC +11.1%、UNIv2 を使うグラフ型より +8.1% と報告。コードは非公開（メール請求）。

## 6. 方向性の案

**A. 倍率の階層を足したプロトタイプ（第一候補）**
- 10× と 5× でも同じ手順（256 画素、Macenko、UNI2-h）で特徴量を抽出する。同じ 256 画素で 10× は 4 倍、5× は 16 倍の範囲を写すので、patch 数は 20× の 1/4・1/16 で済む。
- 各 20× patch に、それを含む 10× と 5× の patch の特徴を対応付けて並べ（または重み付けして連結し）、0035 と同じ手順でプロトタイプを作り、20× だけの場合と比べる。
- 期待: 小葉の中の位置の区別（小葉中心性と辺縁性）、slide 全体に広がる変化の検出。
- 懸念: 倍率ごとの重みの決め方。UNI2-h が 5× の画像でどこまで意味のある特徴を出すか。低倍率の特徴は試験間差（染色のむら）をより強く拾う可能性。

**B. 隣接性の簡単な版（A の比較対象、抽出不要）**
- 既存の 20× の特徴で、各 patch の周り 8 個（または半径 r）の平均を並べる。A で倍率を足した効果が、単に周りを平均した効果と同じかを切り分ける。

**C. GraphTox に近い異常検知（A・B の後）**
- 対照群だけで、patch のグラフ（隣接と倍率の階層）上の Feature Distillation を学び、誤差を異常度にする。比較: patch 単体の kNN 異常検知、単一倍率の Feature Distillation、マルチ倍率の Graph Distillation。評価は異常 patch の Recall@K と slide 単位の AUROC。
- 学習が要り、対照群が試験あたり約 5 枚と少ない点、試験間差が「異常」として出る点が懸念。

**D. プロトタイプ自体の階層（系統樹）**
- 倍率とは別に、粗いプロトタイプ → 細かいプロトタイプの木を作る話。今の木は隣が似ていないので、A の表現で木を作り直すと改善するかも見たい。

## 7. 相談したいこと

1. A の「20× patch に 10×・5× の特徴を対応付けて連結する」やり方は妥当か。より良い組み込み方（注意機構、グラフ、各倍率で別にプロトタイプを作ってから木で結ぶ、など）はあるか。
2. 倍率ごとの特徴の重みや次元のそろえ方を、ラベルなしでどう決めるか。
3. 低倍率で試験間差が強くなる懸念への対処（倍率ごとに順位変換・白色化を別にかけるべきか）。
4. slide 全体に広がる変化（肥大、好酸性変化）を取るには、倍率の階層で足りるか、slide 単位の分布（プロトタイプの構成比など）を使う方が筋か。
5. 評価: patch 単位の正解がない所見について、階層を入れた効果をどう示すか（今は slide 単位の記録の純度、Bayer の held-out、目視）。
6. 抽出の対象を、まず Bayer 230 枚 ＋ 脂肪変性 3 試験 ＋ その対照群に絞るのは妥当か。
