# 0036 計画（2026-11-03）

## 問い

patch 単体（20 倍、約 128 µm 四方）のプロトタイプに、周囲の組織の情報（空間文脈）を足す価値があるか。まず再クラスタリングはせず、既存のプロトタイプの周囲の構成を調べる（第 1 段階）。方針は `experiments/DISCUSSION_20261103_hierarchical_prototypes.md` を他のモデルと相談した結果（H2T の Pattern Co-localization を patch 単位の文脈に応用）。Issue #9 の前段、#15 の手前。

## 設定（2026-11-03 ユーザー確認済み）

- 対象: Bayer 230 枚（全 patch、325 万）＋ 脂肪変性 3 試験 188 枚（全 patch。0035 の A128・split_record の重心に割り当て直す）。
- プロトタイプ: 0035 v1 の A128・split_record（細、876）と、その k=100 の親（粗）。表現と LDA の重みは 0035 と同じ手順で作り直す（全 3,737 枚）。Bayer は最近傍の重心で割り当て直し、0035 の割当との一致率を記録する。
- 近傍: 1 周目（3×3、8 個）と 2 周目（5×5 の外周、16 個）。1 周目の有効な近傍が 5 未満の patch は文脈の解析から外す。
- 対照: slide 内でプロトタイプの割当をシャッフルしたもの（slide 全体の構成は保ち、空間配置だけ壊す）。

## 解析

1. 近傍の有効数（組織の端・血管腔での欠け）と、座標がグリッドに乗っているか。
2. 共起行列（1 周目）。観測/期待（シャッフル）の比。プロトタイプが空間的に固まるか（隣に同じプロトタイプがある割合、実際とシャッフル）。
3. プロトタイプ内の文脈の分かれ方: 有効な patch 300 以上の細プロトタイプごとに、粗の 1・2 周目のヒストグラム（√）で 3 群に k-means。R²（実際とシャッフル）、子の大きさと正味の slide 枚数。候補 = 実際の R² がシャッフルより大きく、子が 10% 以上・正味の slide 5 枚以上。
4. 小葉内の位置: Bayer の中心静脈・門脈域の名前が付いたプロトタイプを目印にし、各 patch から最も近い目印までの距離（patch 単位）で z = d_cv / (d_cv + d_pt)。脂肪変性の純プロトタイプ（0035 の目視で確かめた 10 個）が、CCl4 では中心静脈側、cholesterol 食では門脈域側に寄るか。slide を単位にした区間。目印をシャッフルした対照も。
5. 図: 近傍の有効数、共起、文脈の分かれ方、小葉内の位置、地図（脂肪変性の近傍密度と z）、候補のモザイク（中心 patch と 3×3 の周囲）。

## 注意

- 目印（中心静脈・門脈域）は Bayer のラベルで名前を付けたプロトタイプなので、ラベル由来の情報を使う。ラベルなしの文脈（ヒストグラム）とは分けて読む。目印そのものの確かめ（Bayer の中心静脈・門脈域ラベルの patch の z）は循環を含む。
- 粗プロトタイプは細プロトタイプの親なので、細の中を粗のヒストグラムで分けると「中心の親」が周囲に多く出る。シャッフルとの比較で見る。
- 隣接する patch は独立ではないので、区間は slide を単位にする。
