局所プロトタイプ・ヒストグラムで空間文脈を調べる第 1 段階。設計は `plan.md`。出力は `outputs/0036_20261103_local_prototype_context/<版>/`（git の管理外）。

## v1（2026-11-04、ジョブ 18629、14 分）

対象は Bayer 230 枚の全 patch（325 万）と脂肪変性 3 試験 188 枚の全 patch（322 万）、計 647 万 patch。プロトタイプは 0035 v1 の A128・split_record（細 876）と k=100 の親（粗）。

### 前提の確認

- patch の座標はグリッドに完全に乗る（ずれ 0）。3×3 の近傍が 8 個そろう patch は 92%、5 個以上は 99%（`F1_neighbor_support.png`）。
- Bayer の patch を最も近い重心で割り当て直すと、0035 の割当との一致は 69%。0035 の split_record は「親の中で 5 つに分ける」を 2 回繰り返した割当で、876 個の重心全体からの最近傍とは境界の patch が違う。0036 の中では Bayer・脂肪変性とも最近傍で揃えている。

### 結果

1. **プロトタイプは空間的に固まる**（`F2_cooccurrence.png` 右）。3×3 の近傍のうち同じプロトタイプの割合は、中央値で実際 0.108、slide 内でシャッフルすると 0.009（約 12 倍）。粗プロトタイプの共起（同左）にも、隣り合いやすい群と避け合う群のはっきりしたブロック構造がある。空間文脈には情報がある。
2. **同じプロトタイプの中の文脈の分かれ方は弱い**（`F3_context_split.png`）。861 個の細プロトタイプで、周囲の構成（粗の 1・2 周目のヒストグラム）で 3 群に分けたときの R² は、中央値で実際 0.132、シャッフル 0.090。差はあるが小さい。候補の基準（実際の R² がシャッフルより大きい、子が 10% 以上、正味の slide 5 枚以上）は 468 個を通してしまい、緩すぎた。
   - 差の大きい例（`F6_context_mosaic_*.jpg`）: p0273（胆管増生、差 0.18）、p0751（脂肪変性、0.15）など。p0751 の 3 群は、周囲に多い粗プロトタイプの割合（親 73 が 35〜80%）で分かれているが、モザイクを見る限り見た目の違いははっきりしない。
   - 分かれ方の多くは「周囲に自分の親がどれだけいるか」（＝病変の中心か縁か）で決まっている可能性がある。
3. **小葉内の位置の指標は機能しなかった**（`F4_zonation_fatty.png`、`zonation_fatty.csv`、`zonation_landmark_check.csv`）。
   - 目印（Bayer の中心静脈・門脈域の名前が付いたプロトタイプ、各 5 個）の確かめで、Bayer の中心静脈ラベルの patch の z は中央値 0.35、門脈域ラベルは 0.54（理想は 0 と 1）。目印のプロトタイプには、中心静脈・門脈域以外の patch が多く混ざり、最も近い目印が散らばった偽の目印になっている。
   - 脂肪変性の純プロトタイプの z は、CCl4 で 0.58 [0.56, 0.61]、同じ slide のその他 0.59、目印をシャッフルしても 0.59。cholesterol 食でも差がない。現状の z では小葉中心性・辺縁性は判定できない。
   - 地図（`F5_map_*.jpg` 右）では、z が小葉くらいの大きさの斑の模様になる。小葉の構造を一部拾っている可能性はあるが、目印の精度が足りない。

### 次（v2 で直すこと）

- 目印を、同じ種類の目印が隣に 2 個以上あるまとまり（血管の断面）に限る。Bayer の中心静脈・門脈域ラベルの patch で z が分かれるか（AUC）を確かめてから、脂肪変性で比べる。
- 文脈の分かれ方は、ヒストグラムから自分の親を除いて（周囲の「異なる」構成だけで）分け、子が 2 試験以上に出ることを条件に加える。
- 中間の配列（割当、座標、近傍）を保存し、解析を表現の作り直しなしに回せるようにする。
