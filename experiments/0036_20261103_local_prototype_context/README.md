# 0036 結果まとめ（逐次更新）

局所プロトタイプ・ヒストグラムで空間文脈を調べる第 1 段階。設計は `plan.md`。出力は `outputs/0036_20261103_local_prototype_context/<版>/`（git の管理外）。

## v1（2026-11-04、ジョブ 18629、14 分）

対象は Bayer 230 枚の全 patch（325 万）と脂肪変性 3 試験 188 枚の全 patch（322 万）、計 647 万 patch。プロトタイプは 0035 v1 の A128・split_record（細 876）と k=100 の親（粗）。

### 前提の確認

- patch の座標はグリッドに完全に乗る（ずれ 0）。3×3 の近傍が 8 個そろう patch は 92%、5 個以上は 99%（`F1_neighbor_support.png`）。
- Bayer の patch を最も近い重心で割り当て直すと、0035 の割当との一致は 69%。0035 の split_record は「親の中で 5 つに分ける」を 2 回繰り返した割当で、876 個の重心全体からの最近傍とは境界の patch が違う。0036 の中では Bayer・脂肪変性とも最近傍で揃えている。

### 結果

1. **プロトタイプは空間的に固まる**（`F2_cooccurrence.png` 右）。3×3 の近傍のうち同じプロトタイプの割合は、中央値で実際 0.108、slide 内でシャッフルすると 0.009（約 12 倍）。粗プロトタイプの共起（同左）にも、隣り合いやすい群と避け合う群のはっきりしたブロック構造がある。空間文脈には情報がある。
2. **同じプロトタイプの中の文脈の分かれ方は弱い**（`F3_context_split.png`）。861 個の細プロトタイプで、周囲の構成（粗の 1・2 周目のヒストグラム）で 3 群に分けたときの R² は、中央値で実際 0.132、シャッフル 0.090。差はあるが小さい。候補の基準（実際の R² がシャッフルより大きい、子が 10% 以上、正味の slide 5 枚以上）は 468 個を通してしまい、緩すぎた。
   - 差の大きい例（`F6_context_mosaic_*.jpg`）: p0273（胆管増生、差 0.18）、p0751（脂肪変性、0.15）など。p0751 の 3 群は、周囲に多い粗プロトタイプの割合（親 73 が 35〜80%）で分かれているが、モザイクを見る限り見た目の違いははっきりしない。
   - 分かれ方の多くは「周囲に自分の親がどれだけいるか」（＝病変の中心か縁か）で決まっている可能性がある。
3. **小葉内の位置の指標は機能しなかった**（`F4_zonation_fatty.png`、`zonation_fatty.csv`、`zonation_landmark_check.csv`）。
   - 目印（Bayer の中心静脈・門脈域の名前が付いたプロトタイプ、各 5 個）の確かめで、Bayer の中心静脈ラベルの patch の z は中央値 0.35、門脈域ラベルは 0.54（理想は 0 と 1）。目印のプロトタイプには、中心静脈・門脈域以外の patch が多く混ざり、最も近い目印が散らばった偽の目印になっている。
   - 脂肪変性の純プロトタイプの z は、CCl4 で 0.58 [0.56, 0.61]、同じ slide のその他 0.59、目印をシャッフルしても 0.59。cholesterol 食でも差がない。現状の z では小葉中心性・辺縁性は判定できない。
   - 地図（`F5_map_*.jpg` 右）では、z が小葉くらいの大きさの斑の模様になる。小葉の構造を一部拾っている可能性はあるが、目印の精度が足りない。

### 次（v2 で直すこと）

- 目印を、同じ種類の目印が隣に 2 個以上あるまとまり（血管の断面）に限る。Bayer の中心静脈・門脈域ラベルの patch で z が分かれるか（AUC）を確かめてから、脂肪変性で比べる。
- 文脈の分かれ方は、ヒストグラムから自分の親を除いて（周囲の「異なる」構成だけで）分け、子が 2 試験以上に出ることを条件に加える。
- 中間の配列（割当、座標、近傍）を保存し、解析を表現の作り直しなしに回せるようにする。

## v2（2026-11-04、ジョブ 18634）

v1 の問題を直した版。目印を「同じ種類の目印が隣に 2 個以上あるまとまり」に限り、文脈のヒストグラムから自分の親を除き、候補の条件を厳しくした（R² の差 0.05 以上、子が正味 2 試験以上）。

- 小葉内の位置の指標 z は、まだ機能しない。Bayer の門脈域ラベルと中心静脈ラベルを z で分ける AUC は 0.61。CCl4 の脂肪変性 slide では、まとまった目印がある slide が 64 枚中 11 枚しかない。
- 文脈の分かれ方の候補は 468 → 65 個。上位の p0119（Bayer の最多ラベル: 濃い肝細胞）のモザイク（`v2/figures/F6_context_mosaic_p0119.jpg`）では、3 群が「組織の端の破れた縁」「被膜・血管壁の際」「実質の中の縁」に分かれた。周囲の構成で分かれるのは主に組織の縁の種類で、病理の所見の違いではない。

## v3（2026-11-04、ジョブ 18638、16 分）

小葉内の位置を、0023 で実績のある回帰に替えた。正解は Bayer の中心静脈・門脈域のポリゴンからの距離の比（0 = 中心静脈側、1 = 門脈域側）、特徴は A128 と 1 周目・2 周目の平均（423 次元）、リッジ回帰。予測値の slide 内の順位を位置とする。

- 回帰の評価（試験を分けた 5 分割、202 枚・52,696 patch）: R² 0.22、順位相関 0.43（0023 とほぼ同じ）。`lobular_model.json`。
- **脂肪変性の純プロトタイプは、記録の部位どおりの向きにずれた**（`v3/figures/F4_zonation_fatty.png`、`zonation_fatty.csv`）。slide ごとの平均の平均と、slide を単位にした 95% 区間:

| 化合物（記録の部位） | 純プロトタイプの patch | 同じ slide のその他の patch |
|---|---:|---:|
| CCl4（小葉中心性） | 0.452 [0.445, 0.459]（64 枚） | 0.512 [0.510, 0.514]（67 枚） |
| cholesterol 食（辺縁性） | 0.587 [0.544, 0.628]（17 枚） | 0.501 [0.494, 0.511]（20 枚） |

  - CCl4 の純プロトタイプは中心静脈側へ 0.06、cholesterol 食の純プロトタイプは門脈域側へ 0.09 ずれる。どちらも区間は重ならない。ずれの大きさは控えめ（位置の推定自体の精度が R² 0.22 のため）。
- 注意: 回帰の特徴には中心の patch 自身の表現が入っている。脂肪変性の見た目そのものを「中心静脈側らしい／門脈域側らしい」と読んでいる可能性がある（Bayer の 230 枚に脂肪変性の slide はほぼないので、学習の範囲外の外挿でもある）。周囲だけを使った回帰で確かめる（v4）。
- 目印の z（青）とシャッフル（灰）は v2 と同じで、向きの違いを捉えない。

### 次（v4）

- 回帰の特徴から中心の patch を除き、周囲（1 周目・2 周目の平均）だけで位置を推定しても、同じ向きのずれが出るかを確かめる。
- slide ごとに「純プロトタイプ − その他」の差を出し、何割の slide で記録どおりの向きかを見る。

## v4（2026-11-04、ジョブ 18643）

回帰の特徴から中心の patch を除き、周囲（1 周目・2 周目の平均）だけで小葉内の位置を推定した。

- 回帰の精度はほぼ同じ（試験を分けた評価で R² 0.21、順位相関 0.43）。小葉内の位置の情報はほとんど周囲から来る。
- 脂肪変性の純プロトタイプのずれも同じ: CCl4 0.447 [0.439, 0.453]（その他 0.512）、cholesterol 食 0.585 [0.543, 0.625]（その他 0.501）。
- **slide ごとの差（純プロトタイプ − 同じ slide のその他）**（`zonation_paired_by_slide.csv`）:

| 化合物 | 差の平均 [95% 区間] | 記録どおりの向きの slide |
|---|---:|---:|
| CCl4（中心静脈側が期待） | −0.066 [−0.074, −0.058] | 64 枚中 97% |
| cholesterol 食（門脈域側が期待） | +0.084 [+0.034, +0.131] | 17 枚中 82% |

  目印の z では、それぞれ 36%・63% で、偶然と区別できない。
- 残る懸念: 周りの patch も脂肪変性のプロトタイプであることが多い（同じプロトタイプが隣にいる割合は中央値 0.11、脂肪変性では 0.18〜0.20）。周りの見た目を読んでいる可能性がまだある。v5 で、周囲の平均から脂肪変性・空胞化の記録名のプロトタイプを除いて確かめる。
