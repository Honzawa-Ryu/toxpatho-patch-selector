# 0021 結果まとめ（2026-10-25、試作 v1）

Bayerのアノテーションの61枚と、最大の塊のA_clean（block6_clean、2,231枚の評価用patch）を合わせた約16万patchで、k-means（k=30）のプロトタイプを試作した。設計は`plan.md`。
出力は`outputs/0021_20261025_patch_prototypes/v1/`（gitの管理外）。

## 結果

| 表現 | 次元 | ラベルとのNMI | クラスタの試験数（中央値） | 最多試験の割合（中央値） |
|---|---:|---:|---:|---:|
| unsup（slide内の順位 → PCA64） | 64 | 0.28 | 41.5 | 0.10 |
| weak（slide内の順位 → LDA、Bayerのラベル） | 11 | 0.48 | 42 | 0.12 |

- どちらも、クラスタの多くが40前後の試験にまたがる（試験単位に割れていない）。0017・0018のコア（最多化合物の割合 0.2〜0.8）より大きく改善。
- weakでは、Bayerのラベルにほぼ1対1のプロトタイプが出た（`figures/P1_labels_and_clusters_weak.png`、`figures/sheets/weak/`）。
  - 大きな血管（87%が1クラスタ、純度99%）、壊死（63%、純度96%、13試験）、核分裂像（49%、純度93%、36試験）、濃い肝細胞（74%、純度86%）、中心静脈（50%、純度73%、40試験）、門脈域（59%、純度67%）
  - 画像: 核分裂像のクラスタは化合物を問わず分裂中の核が写る。中心静脈のクラスタは40試験の中心静脈。壊死のクラスタは出血・細胞の脱落・炎症を伴う壊死巣。
- unsupでは、大きな血管・濃い肝細胞・門脈域はまとまるが、壊死・核分裂像は分散する。
- 実質（正常）は、どちらでも多数のクラスタに広がる（ラベルのない大多数のpatchが属する）。

## 限界・次に

- weakの評価は学習に使ったアノテーションと同じなので楽観的（試験外の評価は0020の`supervised_v1`）。
- weakはBayerの12ラベルの方向に寄るので、それ以外の所見（好酸性顆粒状変性、空胞化、胆管増生など）を分ける方向は持たない。unsupと組み合わせる（例: weakの方向を足した表現）余地がある。
- アノテーションのslideを132枚に増やしてから作り直す。外部データはユーザーに確認してから。

## 132枚での作り直し（2026-10-25、`v2_132`）

アノテーション132枚＋block6_clean 2,229枚（約23万patch、66試験）、k=30。表現に combo（LDAの方向＋それを除いた残りのPCA16次元を半分の重み）を追加。

| 表現 | NMI | クラスタの試験数（中央値） | 最多試験の割合（中央値） |
|---|---:|---:|---:|
| unsup | 0.37 | 63.5 | 0.10 |
| weak | 0.51 | 65 | 0.08 |
| combo | 0.49 | 64.5 | 0.09 |

- combo のプロトタイプの例: 核分裂像（52%が1クラスタ、純度84%、61試験）、中心静脈（52%、純度69%、64試験）、門脈域（54%、純度65%、64試験）、濃い肝細胞（73%、純度80%、54試験）、大きな血管（純度99%）。
- **壊死のクラスタ（純度99%）は allyl alcohol が85%**。Bayerの壊死のアノテーション（4,996 patch）の多くがallyl alcoholの大きな壊死巣で、化合物と交絡している。他の化合物の壊死を拾えるかは別に確かめる必要がある。
- t-SNE（`figures/P2_tsne.png`）: weak・comboでは、壊死・大きな血管・核分裂像・門脈域・中心静脈・濃い肝細胞が試験を混ぜた島になる。実質は大きな塊のまま（ラベルの無い大多数）。

## slideの地図と隣接情報（2026-10-25、`v3_maps`、`context_v1`、`context_build_v*`、`explore_v*`、`lobular_probe_v*`）

- `v3_maps`: 組み合わせ版のプロトタイプを全patchに割り当てた地図（14枚）。壊死域（allyl alcohol）はBayerのポリゴンと一致、大きな血管は内腔＋縁取り、組織の縁も帯として出る（ユーザー「辺縁も見れていそうで悪くない」）。実質は斑点状。nitrosodiethylamineのControlの縞は消えた。
- 隣接情報（ProtoGTX arXiv 2610.24023 の空間的な文脈化を、学習なしの8近傍グラフの伝播で近似）:
  - 固定したプロトタイプに割り当て直す（`context_v1`）: 伝播を増やすと隣のまとまり 25%→73%、ラベルとの一致 0.49→0.36。大きいもの（壊死・大きな血管・濃い肝細胞）は保たれ、小さいもの（核分裂像・中心静脈・単細胞壊死）が崩れる。
  - 自分の表現と周りを連結して作り直す（`context_build_v1`、`explore_v1/v2`）: 重みを周りに寄せるほど「まとまり ↑・ラベルとの一致 ↓」の入れ替わり。2段階（周りで粗い領域→自分で細かく）は斑点状に戻る。
- **小葉の構造**: プロトタイプと小葉内の位置（Bayerの中心静脈・門脈域からの距離の比）の一致はどの方法でもほぼ0（NMI 0.025）。
  ところが、同じ表現から位置をリッジ回帰で当てると、slideごとに分けた交差検証で R² 0.18（自分のみ）〜0.28（自分＋周り4回＋16回）。
  学習から外したslideで全patchの位置を予測すると、蜂の巣状の模様になり、**拡大すると青（中心静脈側）の中心に中心静脈、赤（門脈域側）に門脈域が来る**（`lobular_probe_v3/figures/lobular_maps/zoom_*.jpg`）。
  小葉の情報は表現に入っているが、変動が小さく、k-meansでは埋もれる。
- 小葉の軸（上の回帰）をプロトタイプの表現に1次元足す（`explore_v3_lobular`）: 小葉との一致 0.025→0.077、実質のプロトタイプの平均位置の幅 0.35〜0.54 → 0.27〜0.71。ただしラベルとの一致は下がり（0.49→0.45、重み2で0.38）、地図は斑点状のまま。
- 限界: 小葉の軸はBayerの中心静脈・門脈域のポリゴン（約2.8万patch）で学んだ弱教師あり。血管の際のpatchは血管の縁が写ることで当てやすい面もある。
