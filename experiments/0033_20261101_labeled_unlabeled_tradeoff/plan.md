# 0033 計画（2026-11-01）

## 問い（仮説②）

Bayer にラベルのない所見（脂肪変性・空胞化、肥大、胆管増生、好酸性変化、顆粒状好酸性変性）も、①と同じ土台（slide 内の順位 → PCA）の表現でプロトタイプとして取り出せるか。
①では C（LDA 13 次元）が最良、ラベルなし所見では B（Sphering）・D13 が最良で、両方を満たす表現がまだない（0030 v1/v3、0026、0027）。
この実験は、**②に使う表現を 1 つ決める**ための両立評価。

## 候補の表現（土台はすべて slide 内の順位 → 0021 の PCA256）

| 名前 | 中身 | 位置づけ |
|---|---|---|
| D_unsup | PCA 上位 64 | ラベルなし・正規化なし |
| D13_unsup13 | PCA 上位 13 | 次元数を C にそろえた対照 |
| C_lda | LDA 13（Bayer のラベル、21 枚除く） | ①の表現 |
| B_sphering | 試験ごとに対照群で白色化した PCA64 | ラベルなし所見で最良だったもの |
| A_sphering_lda | B ‖ LDA（同じ大きさで並べる） | 0027 で最良 |
| E_unsup13_lda | D13 ‖ LDA | 新。元の表現を次元を落として残し、LDA を並べる |
| F_combo | LDA ‖ 残差 PCA16（重み 0.5） | 0025 の combo。LDA に元の表現の残りを足す |

## 評価（3 つを 1 つの表に）

1. **(a) held-out patch F1**（0031 と同じ）: Bayer 230 枚を化合物単位で 5 分割。分割内で LDA → コンセンサス k-means（k=100）→ 名前付け。評価側の化合物の patch をポリゴンと照合し、実質を除く macro F1。化合物を復元抽出した 95% 区間。
2. **(b) 未学習 slide の読み出し AUC**（0030 と同じ）: Bayer の 230 枚と脂肪変性の 3 試験を除いた 3,319 枚（43 試験）。プロトタイプ構成比（同じ試験の対照群との差）からロジスティック回帰（化合物単位 CV）で所見記録の有無を判別。**ラベルなし 5 所見の平均 AUC が本命**。ラベルあり 5 所見は名前付きプロトタイプ（学習なし）でも。
3. **(c) 脂肪変性の純度**（0026 と同じ）: CCl4（exp 66・67）・cholesterol 食（exp 698）の slide（2,048 patch/slide）で、プロトタイプごとに脂肪変性ありの slide 由来の割合。純度 0.9 以上の数と、程度との Spearman 相関。

(b)(c) のプロトタイプは Bayer 230 枚＋脂肪変性 3 試験（0026 と同じ集合）で作る。学習点は両方から同数（40 万ずつ）。名前付けは Bayer の patch だけ。

## 判断の基準

- (a) で C に近く（差の区間が C を大きく下回らない）、(b) のラベルなし所見で B に近い表現があれば、それを②の表現にする。
- どの表現も両立しなければ、②は「ラベルなし所見用（B または D13）」と「ラベルあり所見用（C）」の 2 本立てにするか、新手法（#14 など）に進むかを相談する。

## 注意（結果を読むとき）

- (b) の読み出しは同じ試験の対照群との差を使うので、試験内の正規化が入っている。
- ラベルなし所見の陽性は化合物数が少ないもの（胆管増生 4、顆粒状好酸性変性 3）がある。
- 脂肪変性の「純度」は slide の記録で見たもので、大滴・小滴の形態を目で確かめた記録はない（目視は今回は飛ばす: 2026-11-01 ユーザー）。
- seed は 1 つ（コンセンサス k-means で揺れは抑えている）。
