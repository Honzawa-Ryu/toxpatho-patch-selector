- (b) の 95% 区間（化合物の復元抽出）は幅 ±0.1 で、B − C は +0.05 [−0.01, +0.11]、A − C は +0.05 [−0.02, +0.11]。有意ではないが向きは一貫している（`differences.csv`）。
- (a) では C が最良。A − C は −0.06 [−0.09, −0.04]、E − C は −0.04 [−0.05, −0.03]、F − C は −0.02 [−0.03, 0.00]。
- **A（Sphering ‖ LDA）が両立の点で最良**: ラベルなし所見では B と同等（差 −0.005）、脂肪変性の純度は最多（6/4）、未学習 slide のラベルあり所見（名前付き）は C と同等（0.829 対 0.826）。ラベルあり patch の F1 だけ C に 0.06 劣る。
- E（D13 ‖ LDA、白色化なし）は次点。F1 は C に近いが、cholesterol 食の脂肪変性（辺縁性）がほぼ取れない（1 個）。
- F（combo）は LDA の性質に近く、ラベルなし所見・脂肪変性で劣る。残差 PCA の重み 0.5 では元の表現が残らない。
- 所見別（`unseen_finding_classification.csv`）: 顆粒状好酸性変性は B・A で 0.99、肥大は 0.74〜0.79 でどの表現も同程度、好酸性変化はどの表現も 0.44〜0.60 で取れない。胆管増生は A が 0.74 で最良。

## 注意

- (b) の読み出しは同じ試験の対照群との差を使うので、試験内の正規化が入っている。
- 脂肪変性の純度は slide の記録で見たもの。各 slide 2,048 patch に間引いているので、0026（全 patch）より数が少ない。表現間の比較が目的。
- seed は 1 つ（コンセンサス k-means）。
- `features_unseen.npz`（未学習 3,319 枚の PCA256、3.5 GB）を保存した。次回は `unseen.features_from` で読み直しを飛ばせる（variants の上書きは浅いので unseen 全体を書く）。
