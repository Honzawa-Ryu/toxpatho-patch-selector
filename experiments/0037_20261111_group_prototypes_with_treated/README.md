# 0037 まとまり 3・26 の対照群＋投与群でプロトタイプを作り直す（2026-11-11）

## 目的と決定（ユーザー、2026-11-11）
- 0035 の control_similarity で「対照群で試験を見分けられない」まとまり 3（13 試験、SS1601）と 26（15 試験、SS1598）を、試験をまたいで比べてよい単位として使う。
- 投与群の特徴量は 0016 `sub_group`（ジョブ 21818、1,641 枚、1 枚 2,048 patch）で用意した。
- 表現は B128 と A128 の両方。まとまりごとに別々に作る。作り方は flat k = 100・200・500・1000 だけ（split・系統樹はなし）。
- 評価は「試験を 1 つ伏せて当てる」（0035 `scripts/group_crossstudy_findings.py` と同じ選び方）＋記録の純度（0035 の (c)）。

## 方法
- 2,269 枚（対照群 561 枚、28 試験）、464.7 万 patch。slide 内の順位 → 0021 の PCA256（0030 と同じ間引き）。
- 白色化 128 次元: 試験ごとに、その試験の対照群の patch で（Ando 2017、0027 の `sphering`）。A128 は Bayer 230 枚のラベルで学んだ LDA 13 次元を連結（0035 と同じ重み）。
- 合議 k-means: 回数・学習点は 0035 と同じ（k=100・200 は 10 回、500・1000 は 5 回、1 回 60 万点）。
- 試験を伏せる評価: 所見の slide と記録のない投与群がそれぞれ 2 枚以上ある試験が 2 つ以上ある所見だけ（13 組）。残りの試験で「所見/まとまりの対照群」と「所見/同じ試験の記録のない投与群」がともに 2 倍以上、投与全般で増えるものは除く。伏せた試験の所見の slide を、選んだプロトタイプの割合で判別した AUC。
- 実行: ジョブ 21957、約 20 分。図は `scripts/group_prototypes_with_treated_figure.py`。

## 結果（`default/`）
- F1（`F1_loso_auc_by_k.png`、`loso.csv`、`loso_summary.csv`）: 対 記録のない投与群の AUC（伏せた試験の平均）
  - 高く安定: まとまり 26 の胆管増生 0.93〜0.97、腫脹 0.87〜0.94、まとまり 3 のすりガラス様 0.78〜0.92（k が大きいほど上がる）
  - 0.7〜0.9: まとまり 3 の肥大（8 試験、0.71〜0.88、k=1000 で最高）、細胞浸潤、まとまり 26 の細胞浸潤・線維化・壊死
  - 低い・偶然に近い: まとまり 3 の好酸性変化 0.48〜0.65
  - k と表現で大きく揺れる組がある: まとまり 3 の核分裂増加（B128 0.44〜0.77）、まとまり 26 の肥大（B128 k=200 で 0.40、ほかは 0.77〜0.90）
  - B128 と A128 の差は一貫しない
- F2（`F2_record_coverage.png`、`record_purity.csv`）: 記録の純度 0.8 以上のプロトタイプに入る割合
  - まとまり 26 の細胞浸潤 0.26〜0.43、まとまり 3 の肥大 0.11〜0.21、すりガラス様 0〜0.15。k を上げると増える
  - ほかの所見はほぼ 0

## 注意
- 学習に使える試験が 1〜2 つの組が多い（13 組中 8 組が 2〜3 試験）。伏せた試験ごとの AUC のばらつきが大きく、k による揺れの多くはこれによる可能性がある。区間は出していない。
- 記録のない投与群は時点をそろえていない（0035 group_crossstudy と同じ）。
- 純度の高いプロトタイプが 1 つの試験だけでできているかは確かめていない。
- 比較の基準（まとまりで作り直さないプロトタイプ、例えば 0035 の全体のもの）を同じ評価にかけていないので、「まとまりで作り直した効果」はまだ言えない。
- Microgranuloma は肝臓・SP_FLG を除く条件で記録が 0 枚だった。

## 比較: まとまりで作り直さない 0035 の全体のプロトタイプ（2026-11-11、ユーザー: 次の候補 1）
- 0035 の flat k = 100〜1000（B128 = v2、A128 = v1）の重心を、0035 の割当から作り直し（`scripts/group_prototypes_global_baseline.py`、出力 `default/baseline_0035/`）、0037 と同じ 2,269 枚・同じ白色化・同じ評価にかけた。A128 の LDA の重みは 0035 の全 patch の値（0036 v5 `a128_scale.json`）。
- 結果（`F1_loso_auc_by_k.png` の点線、`compare_0035_global.csv`）: まとまりで作り直しても上がらない。対 記録のない投与群の AUC の平均は 0037 が 0035 より 0.015 低く、組 × 表現 × k の 102 通りのうち 0037 が上なのは 41。所見ごとの差は −0.06〜+0.04（上回ったのはまとまり 3 の好酸性変化、まとまり 26 の細胞浸潤・腫脹だけ）。0035 のほうが k による揺れも小さい。
- 注意: 0035 の学習には、これらのまとまりの対照群と一部の投与群（0030 の未学習 3,319 枚に入っていたもの）が含まれる。差が小さく、伏せた試験ごとのばらつきの方が大きいので、「全体で作る方が良い」とまでは言えない。言えるのは「まとまりで作り直す利点は、この評価では見えない」こと。
